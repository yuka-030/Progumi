# テスト設計書

## 1. 概要
本ドキュメントは学習アプリにおけるテスト方針・テスト基準・テストケースを定義する。  
※開発段階での検証状況を反映し、主要機能の動作確認が完了している。

---

## 2. テスト方針

### 2.1 テスト実施方針
API単体レベルの動作についてはSwagger UIを用いて疎通およびバリデーション確認を完了しているため、本ドキュメントでは統合およびE2Eの観点を中心に記載する。

| 項目           | 内容                                                               |
|----------------|--------------------------------------------------------------------|
| 対象           | APIロジック / クイズ生成ロジック / 認証・権限制御 / DB操作         |
| 担当           | ④DB                                                                |
| ツール         | Swagger UI / Webブラウザ（手動動作確認）                           |

### 2.2 統合テスト
| 項目           | 内容                                                               |
|----------------|--------------------------------------------------------------------|
| 対象           | Frontend → Backend API → Database の一連の連携フロー                 |
| 担当           | ④DB                                                                |
| 実行タイミング | 随時実施済み（確認完了）                                           |

### 2.3 E2Eテスト
| 項目           | 内容                                                               |
|----------------|--------------------------------------------------------------------|
| 対象           | ユーザー操作シナリオ（ログイン〜クイズ実施〜履歴確認）             |
| 担当           | ④DB                                                                |
| 実行タイミング | 随時実施済み（確認完了）                                           |
